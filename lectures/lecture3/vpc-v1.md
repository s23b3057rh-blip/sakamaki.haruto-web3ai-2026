# Value Proposition Canvas v1

## 顧客像 (Customer Profile)

### 顧客の仕事 (Customer Jobs)
- 味噌汁を安全に運びたい
- こぼさず綺麗なお盆でありたい
- 食事をスムーズに配膳したい

### 悩み (Pains)
- 歩くと汁が波打ってこぼれてしまう
- お盆が味噌汁で濡れてしまって不快
- 人が多いとこだと歩きづらくてこぼれる
- お盆に乗っているお箸なども濡れてしまう
- お盆を拭く用のティッシュが必要
- 熱い汁ものでも安心して持ち運びたい

### 利得 (Gains)
- 片手でも安心して運べる
- 汁ものが揺れにくい
- 配膳が楽になる
- 誰にとっても安心して持ち運べる
- 綺麗なまま食事に入れる

## 提供価値 (Value Map)

### 製品・サービス (Products & Services)
- 配膳時のストレスをなくすプロダクト

### 悩みの解消 (Pain Relievers)
- ノンスリップ素材で滑り防止
- 重心を安定させるつくり
- 器を固定して動かせないように
- 汁の波打ちを抑える器の形状

### 利得の創出 (Gain Creators)
- 配膳が楽しくなる
- 子供でもお手伝いしやすい
- こぼさない自信が生まれる
- 食事を気分よく開始できる
